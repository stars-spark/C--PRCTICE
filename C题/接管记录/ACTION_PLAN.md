# 冲奖修订路线

## 第一阶段：先保住提交有效性

1. 从 Claude 云端工作区找回 LaTeX、完整代码、图源和五份填好的结果表，并推送到原 Claude 分支。
2. 对五份工作簿做非空检查、日期范围检查、144 时段映射检查和汇总列复算。
3. 从 2025-01-01 开始连续模拟 SOC，确认 2025-02-01 的初始 SOC 不是人工重置。
4. 在论文补齐问题二、三指定日期的表 1、表 2、表 3 结果。

## 第二阶段：修正决定奖级的模型

1. 统一问题二真实执行规则：固定日前购电，储能作为实时再调度，最后才紧急购电。
2. 用“计划费 + 紧急费”作为问题二统一评价目标，重新跑安全裕量 U 型曲线。
3. 问题三把调整分段费用直接放入滚动 LP，并加入不调整候选。
4. 预报误差采用滚动历史估计；扩大 `k` 搜索区间，避免未来数据泄漏。
5. 重跑预报组合矩阵：仅 0:00、加入 6:00、加入 12:00、加入 18:00。报告总成本、调整费、紧急费和紧急购电量。

## 第三阶段：论文收口

1. 根据真实模型把“随机优化”改成准确名称；若完成 SAA，再保留随机规划表述。
2. 修正图 15 图例、“第八节”交叉引用、时段映射说明和正文文献引用。
3. 摘要只保留最终复算数字，问题二必须给总成本，问题三结论必须与所选策略一致。
4. 用生成脚本重建全部表格和图，禁止手工复制旧数字。

## 推荐的最低可交付模型

若比赛剩余时间很短，优先做下面的稳健版本，不必冒险上复杂场景树：

- 问题二：严格因果的星期负载预测 + 近日电站预测 + 净负载分位数裕量 + 两日滚动 LP + 实时电池再调度。
- 问题三：滚动偏差校正 + 扩展后的裕量参数 + 调整费用显式线性化 + 可选不调整 + 实时电池再调度。
- 问题四：沿用相同框架，只替换为当日已知的波动电价，并在假设中明确日前可知。

这一方案比当前版本更自洽，也比临时实现不稳定的复杂随机规划更适合冲奖。
