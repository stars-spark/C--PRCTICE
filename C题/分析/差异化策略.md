# 如果全场都用 AI，怎么拉开差距

## 一、先认清 AI 拉平了什么、没拉平什么

**被拉平的**：建模框架。几乎所有队都会交出"确定性 LP + 滚动优化 + 场景法"，这套框架本身不再是亮点，是**地板**。

**没被拉平的四件事**：

1. **数据里藏的东西** —— AI 不主动做数据取证，除非你逼它逐项验证。
2. **信息时序的纪律** —— 大量队伍会在问题2/3 无意识地用当天真实值，自己都不知道。
3. **数字的可信度** —— 框架对不代表结果对。评委横向比对各队的问题2 总成本，数值本身就是硬区分器。
4. **题目真正问的问题有没有被正面回答** —— 例如问题3 明确要求"请分析是否需要引入其他时刻的预报"，很多队会用一句话糊过去。

**结论：不要在"方法新颖度"上卷，要在"执行深度"上卷。**

---

## 二、一个实证，决定主攻方向

我在附件2 上做了 334 天完整回测（固定电价，问题2 设定），得到这张**价值阶梯**：

| 情形 | 总成本（元） | 含义 |
|------|------------|------|
| A. 无储能、完美信息（直购） | **16,407,320** | 上界 |
| B. 有储能、完美信息 | **12,245,047** | 理论下界 |
| C. 有储能 + 朴素预测（最优裕度） | **14,409,547** | 现实可达 |

- **储能价值 = A − B = 4,162,273 元（25.37%）**
- **信息价值 EVPI = C − B = 2,164,500 元（距下界 17.68%）**

安全裕度 z 扫描（z = 对负载上调、对光伏下调的标准差倍数）：

| z | 总成本（元） | 紧急购电（kWh） | 较下界 |
|---|---|---|---|
| 0.00 | 15,855,789 | 603,216 | 29.49% |
| 0.50 | 14,481,885 | 248,733 | 18.27% |
| **0.75** | **14,409,547** | **167,530** | **17.68%** ← 最优 |
| 1.00 | 14,540,626 | 117,861 | 18.75% |
| 2.00 | 15,784,577 | 26,821 | 28.91% |
| 3.00 | 17,564,731 | 3,898 | 43.44% |

**这张表说明了一件关键的事：**

> 那 416 万的储能价值，**每个队的 LP 都会拿到**——因为 LP 谁写都一样。
> 真正分胜负的是那 216 万的 EVPI 缺口——**谁的预测好，谁的成本低**。
>
> **所以：优化不是主战场，预测才是。** 把时间投在打磨 LP 上是投错了方向。

## 三、六个具体动作（按性价比排序）

### 动作1：自我校验三明治（30 分钟，必做，最便宜的保险）

任何一问的结果都必须落在这个夹逼区间里：

```
无储能基线（上界）  ≥  你的结果  ≥  完美信息下界
```

- 问题1：48,052 元 ≥ 你的结果 ≥ 35,127 元
- 问题2：16,407,320 元 ≥ 你的结果 ≥ 12,245,047 元

**落在区间外 100% 是 bug。** 而且把这三个数直接写进论文，就是"结果合理性"的现成证明——大多数队交不出下界，因为他们没想到要算。

### 动作2：把预测作为主攻方向（收益最大）

**不是上 LSTM**（见第四节）。是做这几件对的事：

- **负载**：星期效应（周五六 78,370 vs 其余 124,037 kWh/日）+ 月度季节项（7 月 128,094，11 月 104,104）。"上周同日"已达 MAE 3.83%，还有压缩空间。
- **光伏**：问题2 无预报可用，必须自建。晴空模型 × 近期衰减权重，优于我用的 5 日均值（MAE 151.5 kW）。
- **关键改进：输出分布，不是点估计。** 因为下游是报童问题（见动作3）。
- **更关键：对"净负载 L−PV"直接做分位数预测**，而不是像我这样分别给 L 加裕度、给 PV 减裕度——后者会让有效分位数失控（我的 z=0.75 对应的净负载有效分位数落在 77%~86% 的区间里，不可控）。

### 动作3：用报童模型把"裕度"从调参变成定理（最大的数学亮点）

这是本题**唯一能写出漂亮解析结果**的地方，而且几乎没有 AI 默认会推。

**问题2**：计划单价 c，缺口紧急购电 5c。设净负载 D 随机，计划量 q。

- 少买 1 kWh 的代价：额外 4c（5c − c），概率 P(D > q)
- 多买 1 kWh 的代价：c − v，v 是多买的电存进储能后的回收价值，概率 P(D < q)

一阶条件 → **F(q\*) = 4c / (4c + (c−v))**。取保守情形 v = 0：

> **q\* = 净负载分布的 80% 分位数**

我实证扫出的最优 z\* = 0.75，对应净负载有效分位数 77%~86%——**与理论的 80% 完全一致**。理论与实证互相印证，这是一等奖的写法。

**问题3**：计划 q、调整 a、三段价格。对 q 求导：

- q < a 时，超出部分 1.5c，边际 = c − 1.5c = **−0.5c**
- q > a 时，违约部分 0.5c，边际 = **+0.5c**

一阶条件 → 0.5c·P(a<q) = 0.5c·P(a>q) →

> **q\* = 中位数（50% 分位）**

**这个结论非常反直觉且非常有价值**：问题3 的计划阶段**不应该留安全裕度**，因为调整机制是对称的（多留罚 0.5c，少留补 0.5c）；**裕度应该全部留到调整阶段**（那里才面对 5c 的紧急购电惩罚）。

把"问题2 用 80% 分位、问题3 计划用 50% 分位 + 调整阶段用高分位"这套结论写进论文，配上实证曲线验证，是整篇论文最硬的一块。

### 动作4：价值阶梯 / EVPI —— 让结论带"钱"的单位

不要写"滚动优化效果更好"，要写"**引入 6:00 预报每年节省 X 元，占信息总价值的 Y%**"。这是运筹学的标准语言，绝大多数队不会用。第二节那张表就是模板，问题3 照做一张。

### 动作5：歧义的显式处理（稳健性章节的现成素材）

本题至少 4 处歧义，AI 会默默选一个，**你们要全部列出 + 选定一个 + 做双口径对照表**：

1. **效率口径**：充放各 90%，还是往返总 90%？
2. **问题3 费用公式**：`c·min(q,a) + 0.5c(q−a)⁺ + 1.5c(a−q)⁺`，还是 `c·q + 0.5c(q−a)⁺ + 1.5c(a−q)⁺`？
   **这个必须做**——用动作3 的推导可以证明：第一种读法下最优计划分位数是 **50%**，第二种读法下是 **25%**。口径直接改变最优策略，不说清楚整问的结论都悬空。
3. **问题4 电价是否日前已知**（题面未明确）。
4. **每日终端 SOC 边界条件**（题目只在问题1 要求 0:00=24:00）。不加终端约束，LP 会把电池在年底前榨干；盲目固定 6000 又损失灵活性。正确做法是加**终端储能价值（water value）**，或至少做 `E₂₄ ≥ 6000` 而非 `= 6000`。

### 动作6：问题3 的对照实验矩阵（题目明确要求，别糊弄）

题目原文："请分析是否需要引入其他时刻的预报制定调整购电策略。"这是**送分题**，但要拿满必须做成矩阵而非一句话：

| 预报组合 | 总成本 | 紧急购电量 | 调整费用 | 较仅 0:00 |
|---|---|---|---|---|
| 仅 0:00 | | | | — |
| 0:00 + 6:00 | | | | |
| 0:00 + 6:00 + 12:00 | | | | |
| 全部四次 | | | | |

已有的定量依据：6:00 预报把当天白天（8–17 点）误差从 421.6 降到 222.7 kW（**−47.2%**），而 12:00/18:00 的预报主要指向次日。**可以大胆下结论：6:00 那次是关键，12:00/18:00 边际价值小。** 有数据撑着的大胆结论，比面面俱到的和稀泥更得分。

## 四、三件明确不要做的事

1. **不要上 LSTM/Transformer 预测负载。** 这题的星期效应是近乎确定性的（组内 CV 仅 0.06–0.09），深度模型打不过"上周同日 + 季节项"，还会因样本量小、无法解释被质疑。**简单模型 + 好结果 ≫ 复杂模型 + 差结果。**
2. **不要用遗传算法/粒子群解本可 LP 的问题。** 四问全部可化为 LP（问题4 场景化后仍是 LP）。上启发式是明确的减分项——评委会认为你没看出问题结构。
3. **不要为"创新"硬凑多目标优化。** 题目目标很清楚就是成本最小。硬加"碳排放""用户满意度"等自造目标，会被判为偏题。

## 五、时间该怎么分配（这是最反常识的一条）

大多数队的时间分配会是：**LP 建模 50% + 预测 15% + 写作 35%**。

按第二节的实证，应该是：

| 模块 | 建议占比 | 理由 |
|---|---|---|
| LP 求解器 | **15%** | 谁写都一样，写对即可，不值得打磨 |
| **预测模块** | **35%** | 216 万 EVPI 缺口全在这里，是唯一的成本区分器 |
| 对照实验 + 稳健性 | **20%** | 动作3/5/6，论文的"深度"来源 |
| 结果文件 + 格式校验 | **10%** | 格式错误是最冤的失分 |
| 摘要 + 写作 | **20%** | 摘要评分权重最高 |

---

## 六、一句话

> **所有队的 LP 都会算对那 416 万的储能价值；只有你们能去抢那 216 万的预测缺口。**
> 把"报童分位数"的理论推导 + "价值阶梯"的实证表 + "信息时序审计"的工程纪律这三件事做扎实，
> 方法框架和别人一样也不要紧——**数字比别人好，论证比别人硬，就是差距。**
