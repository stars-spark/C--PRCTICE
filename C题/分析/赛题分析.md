# 2026 国赛 C 题《微网与外部电网电力调控策略》赛题分析

> 来源：全国大学生数学建模竞赛官网 `https://www.mcm.edu.cn/upload_cn/CUMCM2026Problems.zip`（2026-09-10 18:00 发布）
> 题目原文见 `../C题.pdf`，纯文本见 `../C题_题目全文.txt`

## 一、问题本质

这是一道**储能套利 + 两阶段随机优化**题。核心是含储能的微网日前购电计划：

```
购电量 q_t  +  光伏 PV_t  +  放电 dis_t  -  充电 ch_t  ≥  负载 L_t      (∀t)
```

目标是在**分时电价**下最小化购电费用。四问是一条严格递进的主线：

| 问题 | 新增的不确定性 | 数学结构 |
|------|----------------|----------|
| 问题1 | 无（全确定） | 线性规划 LP |
| 问题2 | 负载、光伏未知 | 预测 + LP（两阶段，单次决策） |
| 问题3 | 增加 4 次滚动预报 | 多阶段随机规划 / MPC 滚动优化 |
| 问题4 | 电价也随机 | 波动电价下重做问题2、问题3 |

**评分分水岭不在建模难度，而在"什么时候知道什么信息"。** 决策必须严格只用决策时刻可获得的信息，不能用当天的真实值反算——这是本题最容易犯、也最致命的错误（见第五节）。

## 二、数据结构（已核查）

| 附件 | 维度 | 内容 |
|------|------|------|
| 附件1 | 144 × 4 | 某典型日的电价、小区负载、光伏**预测**功率（问题1专用） |
| 附件2 | 365 × 144 × 2 sheet | 2025 全年逐 10 分钟的小区负载、光伏**实际**功率 |
| 附件3 | 1460 × 24 | 每天 0/6/12/18 时发布的未来 24 小时**整点**光伏预报 |
| 附件4 | 365 × 144 | 2025 全年逐 10 分钟的**波动电价** |
| 附件5 | 5 个 xlsx | 结果模板 |

**无缺失值。** 时间粒度 10 分钟 → 每天 144 个时段，Δt = 1/6 h。

### 关键数据事实

**电价（附件1）有极强的峰谷结构：**

| 时段 | 均价(元/kWh) | | 时段 | 均价 |
|------|------|---|------|------|
| 00–02 | 0.4287 | | 12–14 | 0.7048 |
| 02–04 | 0.4351 | | 14–16 | 0.8480 |
| 04–06 | 0.4830 | | 16–18 | 0.9576 |
| 06–08 | 0.8590 | | **18–20** | **1.3110** ← 尖峰 |
| 08–10 | 1.0302 | | 20–22 | 1.0464 |
| 10–12 | 0.6690 | | 22–24 | 0.4215 ← 谷底 |

峰谷价差 **3.76 倍**（逐点 0.3713 ~ 1.3952；按 2 小时时段均价为 1.3110/0.4215 = **3.11 倍**），远超储能往返效率损失（0.9×0.9 = 0.81，等价套利门槛约 1.235 倍）。**套利空间充足，储能应当被用满。**

**负载有极强的"星期效应"（本题最大的隐藏信息）：**

| | 日均用电(kWh) | 组内变异系数 |
|---|---|---|
| 周五、周六 | **78,370** | 0.091 |
| 其余五天 | **124,037** | 0.057 |

相差 **37%**，而组内几乎无波动。这意味着负载用"上周同一天"即可预测到 **MAE 3.83%**，而"用前一天"只有 14.08%。**日类型（星期几）是负载预测的第一特征。**

**光伏预报质量随发布时刻递增（问题3的定量依据）：**

对同一批白天目标时刻（8:00–17:00）的整点预报误差：

| 发布时刻 | MAE (kW) |
|----------|----------|
| 0:00 | 421.6 |
| **6:00** | **222.7** ← 对当天白天最准 |
| 12:00 | 475.7（多为次日目标） |
| 18:00 | 601.1（多为次日目标） |

配对比较：对当天 8:00–17:00，6:00 预报比 0:00 预报 **误差下降 47.2%**。
→ **问题3"是否需要引入其他时刻的预报"的答案是：需要，且 6:00 那次最关键。** 论文里必须用这个数字说话，而不是空谈"滚动优化更好"。

**波动电价（附件4）不是白噪声，是"基准形态 × 随机因子"：**

- 附件4 的全年平均日形态与附件1 电价形态相关系数 = **1.0000**
- 比值 R = 附件4/附件1 ：均值 1.0000，标准差 0.1798
- R 的**日内相邻时刻自相关 0.812**，日均值序列 lag-1 自相关 0.488
- 价格区间 0.0076 ~ 1.7936（有 9 个点低于 0.05，300 个点低于 0.2）

→ 问题4 应建模为 `c_{d,t} = c_base(t) · R_{d,t}`，R 用 AR(1) / 对数正态刻画。**峰谷骨架不变，只是幅度抖动**——这大幅简化了问题4，也是拿分点。

**光伏出力：** 日均 55,483 kWh，全年 330 天存在光伏过剩时段，过剩总量 312 万 kWh。典型日过剩 6,248 kWh。**过剩光伏必须优先充入储能，否则浪费。**

## 三、逐问建模方案

### 通用符号

- t = 1..144（10 分钟时段），Δt = 1/6 h
- q_t：计划购电量(kWh)；c_t：电价(元/kWh)
- ch_t / dis_t：充电 / 放电电量(kWh，母线侧口径)
- E_t：储能电量(kWh)，E_0 = 6000
- η = 0.9；E ∈ [1200, 10800]；单步最大充放 = 5000 × Δt = **833.33 kWh**

**储能递推（建议口径，须在论文中明确声明）：**

```
E_t = E_{t-1} + η·ch_t − dis_t/η
```

即充电时母线取 ch_t、只存进 η·ch_t；放电时要放出 dis_t 到母线、需消耗 dis_t/η。**这是"充放电效率各 90%"的读法**；另一种读法是往返总效率 90%。两种都能自圆其说，**关键是写清楚并保持全文一致**，评委看的是自洽性。

### 问题1：确定性 LP

```
min  Σ c_t · q_t
s.t. q_t + PV_t·Δt + dis_t − ch_t ≥ L_t·Δt        供电充足
     E_t = E_{t-1} + η·ch_t − dis_t/η
     1200 ≤ E_t ≤ 10800,  E_144 = E_0 = 6000
     0 ≤ ch_t, dis_t ≤ 833.33,  q_t ≥ 0
```

432 个变量的小型 LP，秒解。**不需要 0-1 变量强制"不同时充放"**——因为 η<1 使同时充放严格劣，最优解自动分离；若不放心可加互斥约束验证目标值不变，这条讨论本身就是论文亮点。

**已试算的基准结果（scipy HiGHS，可用于校验你们的代码）：**

| 指标 | 数值 |
|------|------|
| 全天购电量 | **59,482.70 kWh** |
| 全天购电费 | **35,126.95 元** |
| 无储能对照（直购） | 61,789.94 kWh / 48,052.05 元 |
| 储能节省 | **12,925.10 元（26.90%）** |
| 充电总量 / 放电总量 | 20,740.7 / 16,799.9 kWh |
| SOC 范围 | 1200 ~ 10800（上下界均被激活） |

表2 参考值（kWh）：

| 时段 | 充电 | 放电 | | 时段 | 充电 | 放电 |
|------|------|------|---|------|------|------|
| 0–4 | 4500.0 | 0.0 | | 12–16 | 5286.0 | 91.1 |
| 4–8 | 833.3 | 6365.8 | | 16–20 | 0.0 | 5780.1 |
| 8–12 | 4788.0 | 1703.0 | | 20–24 | 5333.3 | 2859.9 |

> 该基准取决于上面的效率口径与"末端 SOC = 初始 SOC"约束；口径不同数值会变，但量级和"谷充峰放"的结构应当一致。

### 问题2：预测 + LP（两阶段）

**这一问的题眼：题目要求输出 2025.2.1–12.31（334 天），而附件2 给的是全年。1 月的 31 天就是留给你做预测训练集的。**

在第 d 天 0:00 决策时，**你不知道当天的 L 和 PV**，只知道第 1..d−1 天的历史。所以必须：

1. **预测** L̂_t、P̂V_t（只用 d 之前的数据，滚动扩展训练集）
2. 用预测值解 LP 得到计划购电量 q_t
3. 用附件2 的**真实值**模拟执行，算出缺口 → 紧急购电（5 倍电价）

费用 = Σ c_t·q_t + Σ 5c_t·(缺口)_t

**负载预测：** 用"星期几 + 近 4 周同类日"的分解模型即可。
`L̂_{d,t} = median{ L_{d−7k,t} : k=1..4 }`，MAE 已测得 4.09%；用"上周同日"MAE 3.83%。可再叠加月度季节项（7 月最高 128,094，11 月最低 104,104）。

**光伏预测（问题2 没有附件3 可用）：** 近 5 日均值 MAE 151.5 kW，优于前一日持续法（185.3 kW）。可用晴空模型 + 近期衰减加权。

**核心策略权衡：** 紧急购电罚 5 倍 → 计划必须**留安全裕度**。建议引入分位数预测：用 L 的高分位、PV 的低分位做"保守净负载"，或直接建 **CVaR / 鲁棒 LP**。裕度参数用 1 月数据（或滚动前若干天）调优，论文里做灵敏度分析画"裕度 vs 总成本"U 型曲线——这是问题2 的最大加分项。

> 注意储能 SOC 的**跨日连续性**：模拟必须从 1 月 1 日 0:00 的 6000 kWh 连续推到年底，2 月 1 日的初始 SOC 由 1 月的执行结果决定，不能每天都重置成 6000。

### 问题3：滚动优化 / MPC（多阶段）

三段电价结构，设计划量 q_t、调整后实际量 a_t：

```
成本_t = c_t·q_t                        计划部分
       + 0.5·c_t·(q_t − a_t)^+          少用（违约）
       + 1.5·c_t·(a_t − q_t)^+ − ...    多用（超出部分单价 1.5c）
       + 5·c_t·(缺口)_t                  紧急购电
```

**实现要点：** 用 `u_t ≥ q_t − a_t, u_t ≥ 0` 和 `v_t ≥ a_t − q_t, v_t ≥ 0` 做标准分段线性化，保持 LP。**目标函数对 a_t 是凸分段线性的，全程 LP 可解，不要上启发式算法**——这题用遗传算法/粒子群反而是减分项。

**滚动流程：**
- 0:00：用 0:00 预报 + 负载预测 → 解 LP → 得全天计划 q_t（**这是要报备的计划量，之后不再改**）
- 6:00 / 12:00 / 18:00：用最新预报更新剩余时段，**q 固定为已报计划**，重优化 a_t 与充放电，付调整费
- 每步只对剩余时段优化，已执行时段的 SOC 作为初值传入

**预报是整点（24 点），数据是 10 分钟（144 点）** → 必须插值。建议用"历史同期日内形态做归一化"再按整点值缩放，比直接线性插值更贴合光伏的钟形出力；至少要做线性插值并在论文中说明。

**"是否需要引入其他时刻的预报"** → 用第二节的数字回答：6:00 预报把当天白天误差从 421.6 降到 222.7 kW（−47.2%），足以覆盖调整费用（多用只罚 0.5 倍差价，而漏供罚 5 倍）。同时要做**对照实验**：只用 0:00 预报 vs 加入 6:00 vs 全用，三条成本曲线一比，结论就立住了。12:00/18:00 的预报主要指向次日，对当天贡献有限——**这是一个可以大胆下的、有数据支撑的结论**。

### 问题4：波动电价

利用第二节的发现 `c_{d,t} = c_base(t) · R_{d,t}`：

- **对问题2 的重算（result4-2）**：0:00 决策时若能观测当天电价（题面未明确），则为确定性电价下的 LP；若不能，需对 R 建模预测。**这个歧义必须在论文假设里挑明并给出你的选择。** 建议主模型取"日前电价已知"（电力市场日前出清的常规设定），再做一个"电价需预测"的对比作为稳健性分析。
- **对问题3 的重算（result4-3）**：电价随机 + 光伏随机，双重不确定。可用 R 的 AR(1)（日内自相关 0.812）生成场景树，做**场景随机规划**或 CVaR。
- **注意极端低价点**（9 个点 < 0.05 元/kWh）：此时充电近乎免费，最优解会激进充电。要检查是否触发功率上限，并在论文中专门讨论——这是展示模型敏锐度的好素材。

**两个必须注意的坑：**

1. **计划购电量表末尾有两列 `全天购电量`、`全天购电费`**（共 147 列 = 日期 + 144 时段 + 2 汇总）。很多队会漏填这两列。
2. **时段标签有偏移。** 模板 144 行/列的标签是 `0:10-0:20`、`0:20-0:30`、…、`23:50-0:00+1`、`0:00+1-0:10+1`，**首个时段是 0:10-0:20 而不是 0:00-0:10**。这与附件中"时间戳 t 代表区间 [t, t+10min]"的读法自洽（附件2 末列正是 `0:00+1`）。
   **操作建议：附件第 k 列 ↔ 模板第 k 行/列，按序号一一对应即可**，并在论文假设中写明这一口径。但要留意：这样"一天"实际是 0:10→次日 0:10，而储能的 0:00/24:00 约束与 `0:00-4:00` 分段统计存在 10 分钟错位，取整到最近时段并说明即可，**不要在这个细节上纠结太久，说清楚比纠结更重要**。

充放电量表填 6 个 4 小时时段的**充电量、放电量合计**，外加 0:00 与 24:00 两个时刻的储电量。紧急购电表按"日期 / 时间段 / 购电量"逐条列出，**连续的缺口时段应合并成一条**（见题目表4 示例）。

## 五、易失分点清单

1. **用未来信息作弊**（最致命）：问题2/3 在 0:00 决策时用了当天的真实负载/光伏。评委一眼看穿，直接掉档。
2. **储能 SOC 不跨日连续**：每天重置为 6000，等于凭空造电。
3. **漏掉紧急购电的 5 倍惩罚**导致计划过于激进，或裕度给得过大导致成本虚高——必须做灵敏度分析找平衡点。
4. **忽略星期效应**：负载预测精度会差 3 倍以上，问题2/3/4 的紧急购电量全线偏高。
5. **用启发式算法解本可 LP 的问题**：本题四问全部可化为 LP（问题4 场景法后仍是 LP），上遗传算法是减分项。
6. **效率口径不声明**或前后不一致。
7. **模板汇总列漏填 / 行列错位**。
8. **问题3 没做"是否需要其他时刻预报"的对照实验**——这是题目明确要求回答的问题，只给结论不给对比实验等于没答。

## 七、一句话总结

**峰谷价差 3.8 倍、储能往返效率 0.81 → 套利必然发生；负载的星期效应几乎是确定性的 → 预测可以做得很准；光伏预报在 6:00 那次质量跃升 47% → 滚动优化的价值有据可查；电价波动只是基准形态乘一个 AR(1) 因子 → 问题4 并不比问题3 难。四问全是 LP，把信息时序守住，就能拿高分。**
